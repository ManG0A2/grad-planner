# 대학원 플래너

수업 시간표 · 캘린더 · 할 일 · 수업/연구 과제별 메모를 한곳에서 관리하는 단일 HTML 앱입니다.
설치나 서버 없이 `index.html`을 브라우저(Chrome/Edge)로 열면 바로 동작합니다.

## 화면 구성

| 화면 | 역할 |
|---|---|
| 홈 | 오늘 수업, 오늘 일정, 기한 지난 일정, 7일 내 일정 요약 |
| 시간표 | 주간 격자. 블록 클릭 시 수업 상세로 이동. 수정은 `+ 수업 추가` / 상세의 `수정`으로 |
| 캘린더 | 월간 달력(일정만 표시, 수업은 시간표에서만). 날짜 클릭 → 우측 패널에서 추가/수정. 완료 항목은 숨김(토글로 표시) |
| 할 일 | 미완료 일정을 기한 지남 / 오늘 / 이번 주 / 이후로 묶어 표시. 체크하면 사라짐. 하단에서 반복 루틴 관리 |
| 수업 / 연구 과제 | 항목별 상세: **일정 · 메모 벽(포스트잇) · 첨부(링크/파일) · 노트** 탭. 메모 벽은 포스트잇을 뜯어 적고 벽에 붙이는 방식 |
| 설정 | 표시 요일·시간표 시작/종료 시각(30분 단위), 기기 간 동기화, JSON 백업/복원, 초기화 |

수업 시간은 5분 단위로 자유롭게 입력할 수 있고(예: 09:00–10:15), 시간표 격자는 30분 단위로 그려집니다.
연구 과제는 **연구 과제 화면 우측 상단 `+ 과제 추가`** 또는 홈 상단 `+ 연구 과제` 버튼에서 추가합니다.

## 반복 루틴 (매주 진행되는 일정)

- **할 일 → 🔁 루틴 추가**, 수업/과제 상세의 일정 탭 → 🔁 루틴 추가, 또는 일정 추가 창의 "루틴으로 추가하기" 링크에서 만듭니다.
- 요일(복수 선택), 시간, 시작일, 종료일(학기 말 등)을 지정합니다.
- 캘린더·할 일·홈에는 지난 7일 ~ 앞으로 28일 치가 자동으로 나타나고(캘린더는 보이는 달 전체), 🔁 표시가 붙습니다.
- 완료 체크는 **그 날짜 회차만** 완료됩니다. 특정 날 회차를 눌러 "이 날만 건너뛰기"로 제외할 수 있습니다.

## 데이터

- 기본은 브라우저 `localStorage`에 저장됩니다 (키: `gradplanner.v1`).
- **설정 → 기기 간 동기화**에 비공개 Gist와 토큰을 넣으면 폰·PC가 같은 데이터를 씁니다 (아래 참고).
- 브라우저 데이터를 지우면 로컬 사본은 사라지므로 동기화를 켜거나 **설정 → JSON으로 내보내기**로 백업하세요.
- 파일 첨부는 2MB 이하만 가능합니다. 큰 파일은 드라이브에 올리고 링크로 추가하세요.
- 첨부한 **파일의 본문은 첨부한 기기에만** 저장됩니다. 동기화로는 파일 이름·크기만 넘어가고, 다른 기기에서는 "다른 기기에 있음"으로 표시됩니다 (Gist 파일 1MB 제한 때문). 여러 기기에서 열어야 하는 파일은 링크로 첨부하세요.

## 폰 + PC에서 쓰기 (GitHub Pages + Gist)

### 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 |
| `manifest.json` | 폰 홈 화면 설치(PWA) 정보 |
| `sw.js` | 오프라인 캐시용 서비스 워커 |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |

### 배포 (한 번)

1. GitHub에 Public 저장소를 만들고 위 5개 파일을 저장소 **루트**에 업로드합니다 (Add file → Upload files).
2. 저장소 Settings → Pages → Build and deployment → Branch를 `main` / `/ (root)`로 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/` 로 접속됩니다.
4. 앱을 수정하면 같은 방식으로 파일을 다시 업로드(덮어쓰기)하면 됩니다.

### 동기화 연결 (기기마다 한 번)

1. gist.github.com 에서 **Secret gist**를 만듭니다. 파일명 `data.json`, 내용 `{}`.
2. GitHub Settings → Developer settings → Personal access tokens → **Tokens (classic)** 에서 `gist` 권한만 있는 토큰을 만듭니다.
3. 앱 → 설정 → 기기 간 동기화에 Gist 주소와 토큰을 넣고 **연결**.
4. 다른 기기에서도 같은 값을 넣으면 됩니다. 이미 데이터가 있으면 어느 쪽을 남길지 물어봅니다.

동작 규칙: 저장 후 1.5초 뒤 자동 업로드, 앱을 열거나 화면으로 돌아오면 자동 다운로드. 더 최근에 저장한 쪽이 이기고, 아직 올리지 못한 로컬 변경이 있으면 로컬이 우선합니다. 왼쪽 아래(폰은 상단 오른쪽)의 ⚪🟡🟢🔴 표시로 상태를 볼 수 있습니다.

### 폰 홈 화면에 설치

- Android Chrome: 메뉴 ⋮ → "홈 화면에 추가" 또는 "앱 설치"
- iPhone Safari: 공유 버튼 → "홈 화면에 추가"

## 단축키

- `Ctrl+Enter` : 폼 저장 / 기억할 내용 추가
